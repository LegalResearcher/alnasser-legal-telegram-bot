# بوت الناصر القانوني لتليغرام

مشروع عربي لإدارة بوت تيليغرام للمصادر القانونية والاختبارات، مع لوحة إدارة، فهرسة ملفات، اشتراكات وإحالات، توثيق زيارات عبر Telegram Web App، وإحصاءات استخدام محكومة بالصلاحيات.

## مكونات المشروع

| المسار | المحتوى |
| --- | --- |
| `client/` | واجهة React وVite الخاصة بلوحة الإدارة والواجهة التعريفية. |
| `server/` | خادم Express، Webhook تيليغرام، منطق الاختبارات والإحالات وإدارة الملفات. |
| `drizzle/` | مخطط Drizzle وترحيلات قاعدة البيانات. |
| `docs/` و`notes/` | التوثيق وملاحظات التصميم والتشغيل. |
| `server/*.test.ts` | اختبارات Vitest للوحدات وتدفقات البوت. |

## المتطلبات

يتطلب التشغيل Node.js 22 أو أحدث وpnpm وقاعدة MySQL/TiDB متوافقة مع Drizzle، إضافة إلى تطبيق بوت تيليغرام وإعدادات OAuth/التخزين المستخدمة في بيئة الاستضافة.

## التثبيت المحلي

```bash
pnpm install
cp env.example .env
# أضف القيم الحقيقية إلى .env محليًا فقط
pnpm db:push
pnpm dev
```

لإنشاء نسخة الإنتاج:

```bash
pnpm build
pnpm start
```

## الاختبارات والتحقق

```bash
pnpm test
pnpm check
```

## متغيرات البيئة

استخدم ملف [`env.example`](env.example) كمرجع لأسماء المتغيرات المطلوبة. أهمها `DATABASE_URL` و`JWT_SECRET` و`TELEGRAM_BOT_TOKEN` و`TELEGRAM_WEBHOOK_SECRET` ومفاتيح Supabase/OAuth.

> **تنبيه أمني:** لا تضع أي قيمة سرية في الشيفرة أو Git أو وثائق المشروع. خزّن القيم الحقيقية في مدير أسرار بيئة الاستضافة أو متغيرات البيئة الآمنة فقط. يحظر `.gitignore` ملفات البيئة والمفاتيح والشهادات وملفات الاعتماد ونسخ قواعد البيانات والسجلات الحساسة.

## قاعدة البيانات

يحتوي مجلد `drizzle/` على المخطط والترحيلات القابلة للمراجعة. هذه الترحيلات تصف البنية فقط ولا يجب استخدام المستودع لحفظ نسخ احتياطية أو بيانات إنتاجية.

## تشغيل Webhook

يستخدم البوت المسار `/api/telegram/webhook`. اضبط `TELEGRAM_WEBHOOK_URL` و`TELEGRAM_WEBHOOK_SECRET` في بيئة التشغيل، ثم سجّل الرابط لدى Telegram من بيئة آمنة.

## سياسة المستودع

المستودع مخصص لملفات المصدر والإعدادات غير السرية والمخططات والاختبارات والتوثيق. لا تُرفع سجلات التشغيل أو محتويات `.manus-logs/` أو `node_modules/` أو نواتج البناء أو قواعد البيانات أو أي مفتاح أو رمز وصول.
